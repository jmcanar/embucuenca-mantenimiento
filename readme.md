# EmbuCuenca - Sistema de Gestión de Mantenimiento Industrial

EmbuCuenca es un sistema informático diseñado para optimizar el mantenimiento de la maquinaria en una planta procesadora de embutidos y derivados cárnicos. Este repositorio alberga específicamente el desarrollo del módulo de Gestión de Órdenes de Trabajo[cite: 1].

## 🌿 Flujo de Ramas (GitHub Flow)

Para garantizar la estabilidad del software en el entorno de producción, el equipo implementa el siguiente flujo de trabajo:

- `main`: Rama principal y estable del sistema. Ningún cambio se commitea directamente en ella.
- `feature/*`: Ramas de desarrollo creadas para implementar tareas o requerimientos específicos (por ejemplo, `feature/gestion-ordenes-trabajo`).
- **Pull Requests (PR):** Mecanismo obligatorio para fusionar las ramas de características hacia `main` tras una revisión previa del código.
